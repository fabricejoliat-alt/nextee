## Points d’attention coach

Lecture seule en production : les entraînements du 7 avril et du 29 septembre 2026 comptent chacun quatre participants. Pour chacun, un participant a un statut coach enregistré et les trois notes complètes ; trois n’ont ni statut coach enregistré ni notes. Les alertes étaient donc partielles, pas des évaluations perdues. L’accueil indique maintenant le nombre restant et la progression. La validation d’un joueur ne clôture pas les évaluations des autres. Les points d’attention sont calculés au chargement ; aucun rappel push quotidien n’est programmé.

## Déclencheurs contrôlés

| Événement | Moment | Destinataires |
| --- | --- | --- |
| Création / modification de planning | Après confirmation de l’enregistrement | Participants, parents autorisés, coachs affectés hors auteur |
| Annulation d’activité / série | Après confirmation de la transaction | Participants concernés, parents autorisés, coachs affectés hors auteur |
| Évaluation individuelle coach | Après sauvegarde confirmée, statut présent | Joueur et parents autorisés ; aucune note privée dans le message |
| Absence / présence du joueur | Après changement confirmé | Coachs affectés ; les deux routes des entraînements passés sont raccordées |
| Message | Après insertion du message | Participants autorisés de la discussion ; résumé générique pour le push |
| Actualité du club | Publication avec notification activée | Audience sélectionnée par le club, accès vérifié ; push selon préférences |
| Compétition | Rappel programmé, passage du cron toutes les cinq minutes | Joueurs inscrits et parents autorisés ; contenu spécifique du rappel conservé |

Les types proposés dans les réglages dépendent du rôle. Les catégories masquées d’un autre rôle ne sont pas désactivées quand on change un réglage. Les canaux désactivés et abonnements révoqués restent respectés.

## Administration

`/admin/notifications` : catalogue, déclencheurs, destinataires, variables cliquables, aperçu fictif et quatre langues. Modifier le français invalide les traductions du brouillon. La traduction IA propose EN/DE/IT sans enregistrer ; la sauvegarde publie les huit champs en une seule instruction. Variables inconnues, accolades incorrectes, traductions ayant perdu des variables et accès non Admin sont refusés. L’audit et la vérification MFA Admin existants restent appliqués.

Les modèles et traductions portent sur les textes fixes. Les valeurs ajoutées par les clubs (titre d’actualité, résumé, détail d’un rappel ou d’une modification) restent leur contenu original ; elles ne sont pas envoyées à l’IA de traduction des modèles.

La migration `20261202_push_subscription_locale.sql` ajoute seulement la langue de chaque appareil. Les appareils existants utilisent le français jusqu’à leur prochaine synchronisation depuis l’application. Les nouveaux messages transportent l’identité du modèle pour permettre le rendu dans la langue du destinataire. Les anciennes notifications sans cette identité conservent leur texte enregistré.
