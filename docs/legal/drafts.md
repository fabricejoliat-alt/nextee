# Brouillons structurés — non publiables en l'état

Tous ces modèles portent le statut **À valider juridiquement**. Ils ne décrivent pas des pratiques confirmées. Les champs `À renseigner` doivent provenir de l'exploitant et des clubs, avec revue juridique et traduction humaine FR/EN/DE/IT avant publication.

| Type | Audience et action | Structure proposée, avec champs obligatoires |
|---|---|---|
| CGU plateforme | Utilisateur adulte ; accepter | Identité et contact de l'exploitant **[À renseigner]** ; description et limites du service ; conditions de compte ; mineurs et représentant ; rôles et clubs ; contenus publiés ; suspension/fin d'utilisation ; droit et juridiction **[À valider]** ; date/version. La case « J'accepte les conditions d'utilisation » concerne le contrat seulement. |
| Information sur les données | Tous ; prendre connaissance si exigé | Responsables et rôles club/plateforme par finalité **[À déterminer]** ; catégories de données ; finalités et bases envisagées ; destinataires et prestataires **[À renseigner]** ; transferts **[À vérifier]** ; durées **[À définir]** ; droits et contact ; traceurs/permissions ; date/version. La case dit « J'ai pris connaissance », sans consentement général. |
| Autorisation d'usage par enfant | Représentant qualifié, par enfant et portée ; autoriser | Identité du service et du club ; enfant identifié dans la présentation ; qualité du signataire et mode de vérification ; fonctions permises ; conditions de retrait/fin ; règles d'âge et juridiction **[À valider]** ; confirmation e-mail indépendante. Ne pas confondre avec consentement à tous les traitements. |
| Consentement spécifique | Personne concernée ou représentant selon règle validée ; consentir/refuser/retirer | Finalité unique **[À renseigner]** ; données ; destinataires ; caractère facultatif ; conséquences du refus ; durée ; retrait et propagation ; mécanisme de résolution entre représentants. Préparer séparément images, marketing et partages si ces finalités existent réellement. |
| Notice junior simplifiée | Junior ; lire ou accusé adapté si validé | Qui voit quoi ; comment demander de l'aide ; photos/messages ; choix et droits exprimés dans un langage accessible. Complément de la notice complète, jamais substitut. |

Variables de gabarit prévues après `20261022_legal_template_rendering.sql` : `{{child_name}}` (enfant bénéficiaire distinct de l'acteur), `{{club_name}}` (document de club) et `{{user_name}}` (acteur). Le moteur refuse une valeur absente et conserve le texte exact rendu dans la preuve. La publication refuse les variables non déclarées ou altérées dans une traduction. Aucune identité réelle n'est envoyée à l'outil de traduction. L'activation demeure soumise à une validation juridique et aux tests sur base isolée.
